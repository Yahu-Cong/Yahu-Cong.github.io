CS280 Project 3

Overview

Flow matching models. Part A explores a pretrained text-to-image flow model (PixNerd) without any training. Part B builds and trains a UNet-based flow matching model from scratch on MNIST.

Part A: Exploring the Power of Flow Models

1.1: Constructing noisy training inputs

interpolate(image, noise, t) = t*image + (1-t)*noise. t=0 is pure noise, t=1 is the clean image.

1.2: Classical denoising

Gaussian-blurring x_t / t at each noise level, best blur sigma picked per level.

Blurring recovers a rough shape but never the actual texture/detail.

1.3: One-step denoising

one_step_denoise(x,t) = x + (1-t)*v(x,t), prompt "a high quality photo".

Much better than the Gaussian blur baseline, especially at higher t.

1.4: Visualizing velocity

At each t: the noisy image, the predicted update (1-t)v̂, the ground-truth update (1-t)v_gt, and a per-pixel RMS error map. Updates use a signed RGB scale centered at middle gray.

1.5: Iterative denoising with Euler sampling

25 Euler updates (h=0.02) starting from the saved t=0.5 noisy image.

Compared against the original, the blur baseline, and one-step denoising:

Euler sampling from t=0.5 reconstructs the image almost exactly, far closer than either baseline.

1.6: Generating images from noise

Five independent Gaussian starting states, 50 Euler updates from t=0 to t=1, prompt "a high quality photo", seeds 180–184.

All five land on different generic photo subjects, since the prompt gives the model nothing to narrow down to.

2.1: Classifier-free guidance

v_cfg = v_c + w*(v_c - v_u), w=7, same seeds as 1.6.

Sharper and more coherent than the unguided samples in 1.6.

3.1: Image-to-image editing

edit starts from t_start*image + (1-t_start)*noise and runs CFG Euler sampling to t=1, prompt "a high quality photo", starting times 0.02–0.50.

Lower starting time means less of the original survives; by t=0.5 the edit is nearly the original image back.

Hand-drawn and web images

Part B: Flow Matching from Scratch

1.2: Visualizing the noising process

z = x + sigma*eps, sigma = 0.0 to 1.0.

1.2.1: Training the single-step denoiser

sigma=0.5, D=128, batch size 256, 5 epochs, Adam lr=1e-4.

1.2.2: Out-of-distribution testing

Same model, sigma swept from 0.0 to 1.0 on the test set.

Holds up reasonably well past the training sigma, then degrades as the input gets noisier than what the model ever saw.

1.2.3: Denoising pure noise

Same architecture and training recipe, but the input is pure noise (z = eps) instead of a noised digit.

The output is a blurry circle rather than any specific digit. Since there's no information about the label in the input (it's pure noise), the velocity points toward the average of all the digits, which looks like a circle.

2.2: Training the time-conditioned UNet

D=64, batch size 64, Adam initial lr=1e-2, ExponentialLR with gamma=0.1^(1/10), 10 epochs.

2.3: Sampling from the time-conditioned UNet

Digit-like strokes by epoch 5, more legible shapes by epoch 10, but no class control yet.

Bells & whistles: a better time-conditioned UNet

Wider/more expressive architecture variant (TimeConditionalUNetBW), same training recipe.

2.5: Training the class-conditioned UNet

Adds a one-hot class vector with p_uncond=0.1 dropout for classifier-free guidance. D=64, batch size 64, Adam initial lr=1e-2, same exponential schedule, 10 epochs.

Learning-rate scheduler ablation

Same architecture and data, trained again without the scheduler at a constant lr=5e-3 (roughly the geometric mean of the scheduled run's start and end learning rates, chosen as a one-value compromise between the scheduled run's fast-but-unstable early steps and its fine-tuned later ones).

2.6: Sampling with classifier-free guidance

Guidance scale gamma=5.0, four instances of each digit 0–9, epochs 1/5/10, scheduled run:

Same sampling, no-scheduler run:

Both converge to clean, correctly-labeled digits by epoch 10. The scheduled run gets there with a decaying learning rate (1e-2 down to 1e-3); the constant-lr run compensates with a smaller fixed step size throughout so training doesn't destabilize in the later epochs.
